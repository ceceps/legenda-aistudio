Pipeline — 7 Stage End-to-End

① Master Prompt→ ② Screenplay→ ③ Asset Generation→ ④ Music & Audio→ ⑤ Storyboard→ ⑥ Video Scenes→ ⑦ Final Merge

Stage Detail

1
Master Prompt → Full Screenplay (Naskah Lengkap)

AI: Gemini 2.0 Flash (generasi teks panjang, structured JSON output)

  • Daftar aktor + deskripsi persona + kostum tiap karakter
  • Dasar cerita, konflik utama, resolusi
  • Latar / setting per scene (nama tempat, waktu, suasana)
  • Voice Over / Narator script per scene
  • Petunjuk musik latar (mood, tempo, instrumen)
  • Plot breakdown: Pembuka → Rising Action → Klimaks → Resolusi
2
Asset Generation — Karakter, Item, Background

AI: NVIDIA Nemotron (image generation prompt crafting) + Image model via Composio API

  • Generate prompt visual karakter tiap aktor (wajah, tubuh, kostum, gaya era)
  • Generate prompt visual item utiliti (senjata, properti, aksesori)
  • Generate prompt visual latar belakang per scene (background environment)
  • Output: daftar prompt → disimpan ke DB → antri job image gen
3
Music & Audio Generation

AI: Suno API (musik & lirik), Gemini (prompt lyric craftting)

  • Soundtrack Lagu: prompt lirik + genre → Suno generate lagu bertema cerita
  • Backsound Instrumen Cinematic: prompt "no vocals, cinematic orchestral, [mood]" → Suno
  • Voice Over / Narator: teks narator → Text-to-Speech (Google TTS / Gemini TTS)
4
Storyboard Generation — Per Scene (10 detik)

AI: Gemini (layout & komposisi) + Nemotron (visual prompt)

  • Setiap scene → 1 storyboard card: gambar komposisi, angle kamera, aksi karakter
  • Anotasi: durasi, transisi, voice over snippet, musik aktif
  • Estimasi total scene: 18–22 scene untuk video ≥ 3 menit
  • Storyboard disimpan sebagai JSON + preview image di storage
5
Video Generation — Per Scene

API: Composio (orchestrate video gen tool) → Runway / Kling / Hailuo (10 det/scene)

  • Input: storyboard prompt + asset gambar karakter + background
  • Setiap scene di-generate sebagai clip 10 detik
  • Job antrean async; status real-time via WebSocket ke frontend
  • Clip tersimpan di Google Drive folder per project
6
Final Video Merge

Tool: FFmpeg (via Docker container job)

  • Gabung semua clip scene secara berurutan
  • Mix audio layer: Backsound instrumen (volume rendah) + Soundtrack + Voice Over (foreground)
  • Tambah fade in/out, title card, credit akhir
  • Export: MP4 H.264, 1080p, ≥ 3 menit
  • Upload otomatis ke Google Drive → generate shareable link
  • User bisa download langsung dari aplikasi

UI Flow — Halaman Utama

  1. Halaman Create — Form master prompt (IDE, GAYA, TOKOH, ASAL, LATAR, PLOT) → tombol "Generate Cerita"
  2. Halaman Naskah — Tampil screenplay lengkap (aktor, plot, scene list) → konfirmasi lanjut
  3. Halaman Pipeline Progress — Real-time progress bar 7 stage via WebSocket (Asset → Audio → Storyboard → Video → Merge)
  4. Halaman Storyboard — Grid tiap scene: gambar + teks VO + info musik
  5. Halaman Preview & Download — Video player HTML5, tombol Download, link Google Drive
